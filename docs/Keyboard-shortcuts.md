# Keyboard shortcuts

| Shortcut | Action |
|---|---|
| `⌘O` | Open Workspace… |
| `⇧⌘T` | New Terminal in workspace |
| `⌘W` | Close active tab |
| `⌘\` | Split focused pane to the right |
| `⌘⇧\` | Split focused pane downward |
| `⌘]` | Focus next pane |
| `⌘[` | Focus previous pane |
| `⌘F` | Find (in markdown source/split panes — uses the system find bar) |
| `⌘Z` / `⌘⇧Z` | Undo / redo (in markdown source/split panes) |

## Drag interactions

| Drag | Effect |
|---|---|
| Drag a tab over another pane | Compass appears — drop on an arrow to split |
| Drag a tab onto a tab strip | Merges as a tab in that pane |
| Drag the title-bar strip (top 28pt) | Move the window |
| Double-click the title-bar strip | Maximize / restore (honours your system title-bar setting) |

## Canvas mode

| Gesture | Effect |
|---|---|
| Drag a file/sticky | Move it on the canvas |
| Trackpad pinch | Zoom |
| Two-finger drag (no item) | Pan the canvas |
| Drop a file from Finder onto the canvas | Add it as a card at that location |
| Right-click an item | Delete |
